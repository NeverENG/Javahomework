### MyShop 终端设计

#### Version 1 要求 ：
    - 登录页面 输入 1 登录系统 输入 2 退出
    健壮性考虑 输入 1 2 以外的值报错并 for 重试
    - 输入完毕进入对应页面 
#### Version 2 要求：
    - 在Version1.0的基础上，实现图1-2中的具体功能，比如客户信息管理、输出购物小票和计算积分功能。客户信息包括：姓名、手机号、会员卡号、会员等级（银/金/铂金）、入会时间等；小票中应包括：购物物品、单价、会员价、数目、金额、消费总金额、总折扣、实际缴费。会员积分规则（每消费100元可获得4分，每年200积分、500积分以上升级会员等级、年底积分兑换礼物清零活动等）

        - 获取所有用户的信息
        - 根据用户名模糊查找
        - 添加用户

    }
    2. 小票{
        - 输入小票id 获取对应的小票
    }
    3. 会员积分{

    }

#### Version3.0：模拟幸运抽奖。
商场推出幸运抽奖活动，抽奖规则如下：客户的4位会员卡号的各位数字之和大于20，则为幸运客户，判断是否幸运客户，在购物结算时，实行免单。
